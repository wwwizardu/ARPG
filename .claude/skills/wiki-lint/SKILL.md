# wiki-lint

위키(`Wiki/`)와 원본(`Doc/`, 코드)의 정합성을 점검한다. **읽기 전용. 수정 금지. 리포트만.**

## 스케일 원칙 (중요)
코드베이스가 20만 줄이 넘으므로 **절대 전체를 읽지 않는다.** 증분으로 좁힌다.

1. 마지막 lint 지점을 확인한다: `Wiki/.lint-state`에 저장된 커밋 해시. 없으면 사용자에게 물어 베이스라인을 정한다.
2. 그 이후 바뀐 파일만 뽑는다: `git diff <해시>..HEAD --name-only`.
3. 바뀐 파일과 **연결된 위키 페이지만** 대상으로 삼는다(각 페이지 프론트매터의 `sources:`로 역추적).
4. 대조는 **위키 → 원본 방향**으로만: 위키 페이지의 각 주장을 읽고, 그 `[src:...]`가 가리키는 원본 지점만 grep/열람해 확인한다. 원본 전체를 훑지 않는다.

## 리포트 항목 (이것만 본다)
- **모순**: 위키 주장 ≠ 현재 원본/코드. (위치, 위키가 뭐라 하는지, 원본이 뭐라 하는지)
- **누락**: `sources:`의 원본은 바뀌었는데 위키에 반영 안 됨.
- **고아 페이지**: `sources:`가 가리키는 원본이 삭제/이동됨.
- **끊긴 출처**: `[src:...]`가 존재하지 않는 경로/라인을 가리킴.
- **끊긴 교차참조**: `[[페이지]]`가 없는 페이지를 가리킴.

## 출력 형식
표가 아니라 목록으로, 심각도 순(모순 → 누락 → 나머지). 각 항목에 "어느 위키 페이지 / 어느 원본 / 무엇이 어긋났나"를 적는다.
**아무것도 자동으로 고치지 않는다.** 끝에 "이 중 어떤 걸 반영할까요?"로 사람에게 넘긴다.

## 종료 시
점검한 범위(HEAD 커밋 해시)를 `Wiki/.lint-state`에 기록할지 사용자에게 확인한다.
