# 인벤토리 장착 아이템 비교 UI 기획

> 상태: 제안 초안, 구현 전
> 작성일: 2026-10-12
> 개정: 2026-10-12 사용자 결정으로 Shift 유지 비교, 화면 위치 기준 좌·우클릭 장착, 비교 중 드래그 금지를 적용하고 Tab 슬롯 전환을 제거했다.
> 범위: 플레이어 인벤토리의 장비와 해당 슬롯의 현재 장비 비교

플레이어는 인벤토리 장비에 마우스를 올려 기존 단일 툴팁을 보고, **Shift를 누르고 있는 동안** 현재 장착 아이템과 수치·옵션을 비교한다. 비교 중에는 좌클릭으로 장비 화면의 왼쪽 칸, 우클릭으로 오른쪽 칸에 바로 장착한다. 무기·반지·귀걸이처럼 칸이 두 개인 장비는 두 장착 아이템을 함께 보여준다.

Shift 유지 비교, Tab 전환 제거, 화면 위치 기준 좌·우클릭 장착, 비교 중 드래그 금지는 사용자 결정이다. 그 밖의 화면·표시 세부 규칙은 이번 기획의 제안이다. 최종 전투력 예측은 후속 단계로 두고, 첫 구현은 아이템 자체의 능력과 옵션 차이를 정확히 보여주는 데 집중한다.

## 이용 흐름과 조작

1. `I` 키로 인벤토리를 연다.
2. 인벤토리 장비에 마우스를 올리면 기존 단일 툴팁을 표시한다. 툴팁 맨 아래에는 구분선과 `[Shift] 비교` 안내를 붙인다.
3. **Shift를 누르고 있는 동안** 비교 툴팁으로 바꾸고, 떼면 단일 툴팁으로 돌아간다. Shift를 누른 채 다른 장비로 옮기면 대기 없이 바로 비교를 표시한다.
4. 장비 화면에서 비교 대상 슬롯을 테두리로 강조한다. 칸이 두 개인 장비는 두 칸을 모두 강조한다.
5. 비교 중 **좌클릭은 화면 왼쪽 칸, 우클릭은 화면 오른쪽 칸**에 바로 장착한다. 칸이 하나인 장비는 어느 버튼이든 그 칸에 장착한다. 휠 클릭은 비교 중 장착하지 않는다.
6. Shift 없이 클릭하면 현행 동작대로 `GetBestSlot`의 자동 선택 규칙으로 장착한다.
7. 슬롯에서 마우스가 나가거나 인벤토리를 닫으면 비교와 슬롯 강조를 없앤다.

비교 툴팁 아래에는 실제 결과를 적는다. 칸이 두 개인 장비는 `좌클릭: 오른쪽 반지와 교체 · 우클릭: 왼쪽 반지에 장착`, 칸이 하나인 장비는 `클릭: 갑옷과 교체`처럼 표시한다. 별도의 비교 창, 비교 버튼, 슬롯 전환 키는 두지 않는다.

`[Shift] 비교` 안내는 인벤토리 장비에만 붙인다. 장착 슬롯·스킬북·스킬 페이지·소비 아이템 툴팁에는 붙이지 않는다. 해당 장착 칸이 비어 있어도 비교 화면에서 들어갈 칸을 확인할 수 있으므로 안내를 표시한다. Shift 아이콘은 테두리와 둥근 모서리 안에 `Shift` 글자를 넣은 키캡 모양을 USS로 그리며 별도 이미지는 추가하지 않는다.

Shift는 UI 입력 액션으로 연결하고 왼쪽·오른쪽 Shift를 모두 받는다. 인벤토리 장비를 호버하는 동안에만 비교를 열며, 다른 UI가 전면에 있거나 입력 필드가 포커스를 가진 경우에는 동작하지 않는다. 같은 키가 Player 맵의 `Sprint`에도 연결되어 있다. 현재는 달리기 값을 소비하는 곳이 없지만, 인벤토리를 연 채 이동할 수 있으므로 달리기를 구현할 때 비교 중 Shift 입력과의 분리를 함께 정한다.

**모드는 마우스 버튼을 누르는 순간의 Shift 상태로 정한다.** 비교 중 누른 버튼은 드래그를 시작하지 않고 바로 장착한다. Shift 없이 시작한 드래그는 도중에 Shift를 눌러도 드래그로 유지하고 비교 툴팁을 띄우지 않는다. 드래그 앤 드롭 자체는 후속 확장이다.

장착하면 양쪽 슬롯 데이터를 동기화하고, 포인터가 있는 인벤토리 칸의 현재 내용으로 표시를 다시 만든다. Shift를 계속 누르고 있으면 칸으로 돌아온 이전 장비와 새로 장착한 아이템의 비교로 바로 바뀐다. Shift를 누르지 않았다면 돌아온 장비의 단일 툴팁을 표시한다. 빈 슬롯에 장착해 칸이 비면 툴팁을 닫는다. 장착·해제·아이템 제거 등으로 비교 데이터가 바뀌면 이전 표시를 계속 유지하지 않는다.

## 비교 대상 슬롯

**장착 가능한 슬롯**을 대상으로 비교한다. 무기 계열이나 아이템 이름이 같아야 한다는 제한은 두지 않는다.

| 인벤토리 장비 | 비교 카드 | 비교 중 클릭 | Shift 없는 클릭 |
| --- | --- | --- | --- |
| 투구·갑옷·장갑·장화·목걸이·허리띠 | 해당 부위 한 장 | 좌·우클릭 모두 해당 슬롯 | 해당 슬롯 |
| 방패 및 현행 Shield 분류의 보조 장비 | 왼손 한 장 | 좌·우클릭 모두 왼손 | 왼손 |
| 무기 | 오른손·왼손 두 장 | 좌클릭 오른손, 우클릭 왼손 | 오른손이 비었으면 오른손, 왼손이 비었으면 왼손, 둘 다 차면 오른손 |
| 반지 | 오른쪽·왼쪽 반지 두 장 | 좌클릭 오른쪽 반지, 우클릭 왼쪽 반지 | 오른쪽이 비었으면 오른쪽, 왼쪽이 비었으면 왼쪽, 둘 다 차면 오른쪽 |
| 귀걸이 | 오른쪽·왼쪽 귀걸이 두 장 | 좌클릭 오른쪽 귀걸이, 우클릭 왼쪽 귀걸이 | 오른쪽이 비었으면 오른쪽, 왼쪽이 비었으면 왼쪽, 둘 다 차면 오른쪽 |

좌·우클릭은 슬롯 이름이 아니라 **장비 화면의 위치**에 대응한다. 장비 화면에서 오른손·오른쪽 반지·오른쪽 귀걸이는 화면 왼쪽에 있으므로 좌클릭 대상이다. 이렇게 하면 누르는 버튼과 바뀌는 칸이 같은 쪽에 있고, 무기는 가장 자주 쓰는 좌클릭이 주무기 교체가 된다. 두 칸이 모두 찼을 때 Shift 없는 클릭이 고르는 칸과 비교 중 좌클릭의 결과도 같다. [src: Assets/UI/Character/Character.uss 장비 칸 배치(2026-10-24 이전 Assets/Prefabs/UI/Prob/CharacterUI.prefab), Assets/Scripts/Common/Utility/EquipHelper.cs `GetBestSlot`]

장착 카드 제목은 `좌클릭 — 오른쪽 반지`처럼 버튼과 부위를 함께 적는다. 칸이 하나인 장비는 `현재 장착 — 갑옷`처럼 부위만 적는다.

빈 슬롯은 해당 카드에 `장착된 아이템 없음`을 표시하고 차이를 붙이지 않는다. 빈 슬롯을 기준으로 모든 옵션에 녹색 증가 표시를 붙이지 않는다. 예를 들어 오른쪽 반지만 있다면 좌클릭 카드는 오른쪽 반지, 우클릭 카드는 `장착된 아이템 없음`이며, 우클릭하면 빈 왼쪽 칸에 장착한다.

왼손에 방패가 있는 상태에서 무기를 비교하면 우클릭 카드가 방패다. 두 아이템의 서로 다른 능력을 모두 표시하고, 무기 전용 피해와 방패의 방어 능력을 하나의 점수로 환산하지 않는다. 안내에는 `우클릭: 왼손 방패와 교체`처럼 교체 대상을 적는다.

현행 코드는 왼손에 Weapon 또는 Shield를 허용한다. 대검·활·석궁·지팡이의 양손 장착과 보조 장비 금지는 별도 확정 설계이며 아직 구현 전이다. 첫 비교 UI는 현행 장착 판정을 사용하고, 양손 규칙이 구현될 때 비교 후보와 실제 장착 판정을 함께 갱신한다. 그 단계에서 양손 무기는 좌·우클릭 모두 오른손에 장착하고, `오른손 교체 + 왼손 해제`를 한 교체 결과로 표시해야 한다. ## 화면 구성

칸이 하나인 장비는 **선택한 아이템·현재 장착** 두 장, 칸이 두 개인 장비는 **선택한 아이템·좌클릭 대상·우클릭 대상** 세 장을 인벤토리 슬롯 옆에 하나의 묶음으로 배치한다. 선택한 아이템은 항상 맨 왼쪽에 두고, 장착 카드는 마우스 버튼의 좌우에 맞춰 좌클릭 대상·우클릭 대상 순서로 놓는다. 묶음이 오른쪽 화면 밖으로 나가면 슬롯 왼쪽으로 옮기되 카드 순서는 유지한다.

| 선택한 아이템 | 좌클릭 — 오른손 | 우클릭 — 왼손 |
| --- | --- | --- |
| 강철 검 · Tier 2 · 아이템 레벨 12 | 철 검 · Tier 1 · 아이템 레벨 5 | 장착된 아이템 없음 |
| 물리 피해 12~18 | 물리 피해 8~12 · 교체 시 **+4~+6** | |
| 초당 공격 횟수 1.20 | 초당 공격 횟수 1.40 · 교체 시 **-0.20** | |
| 무기 치명타 확률 5% | 무기 치명타 확률 4% · 교체 시 **+1%p** | |
| 무기 고유 강화 상세 | 무기 고유 강화 상세 | |
| 접두 · 최대 체력 +20 | 접두 · 최대 체력 +12 · 교체 시 **+8** | |
| — | 접미 · 냉기 저항 +8% · 교체 시 **제거** | |
| 접미 · 화염 저항 +10% | — · 교체 시 **추가** | |

하단 안내: `좌클릭: 오른손 철 검과 교체 · 우클릭: 왼손에 장착`

위 수치는 화면 표현을 위한 가상 예시이며 실제 아이템 밸런스가 아니다.

모든 카드에 같은 항목 순서를 적용하고, 어느 한 카드에만 있는 항목도 나머지 카드에 같은 위치를 확보한다. 이름·등급·아이템 레벨에는 우열 색을 붙이지 않는다. 기존 등급 색은 유지하고, 능력 차이의 색은 `교체 시` 수치에만 적용한다.

카드 폭은 기존 툴팁의 220~320 패널 단위를 기준으로 하고 카드 사이에는 약 8 단위를 둔다. 실제 크기는 폰트와 옵션 길이에 맞춰 조정한다. 카드가 가용 폭에 들어가지 않으면 선택한 아이템을 위에 두고, 장착 카드를 아래에 좌클릭·우클릭 순서로 쌓는다. [src: Assets/UI/Tooltip/Tooltip.uss]

옵션이 길면 묶음 높이를 가용 화면 높이의 약 75%로 제한하고, 헤더·조작 안내를 고정한 채 본문을 스크롤한다. 인벤토리 슬롯 위에서 휠을 돌리면 비교 본문을 스크롤하며 인벤토리 스크롤과 중복 처리하지 않는다. 정렬된 모든 카드 본문은 함께 스크롤한다. 툴팁은 포인터 입력을 가로채지 않아 슬롯 클릭과 호버가 유지되어야 한다.

## 능력 차이 표시

표시하는 차이는 **선택 아이템의 수치 − 해당 장착 아이템의 수치**다. 차이는 각 장착 카드의 값 옆에 `교체 시`와 함께 적어, 그 칸을 선택 아이템으로 교체했을 때 달라지는 값을 보여준다. 칸이 두 개인 장비는 카드마다 각자의 차이를 표시하고, 칸이 하나인 장비도 같은 위치를 사용한다. 하단에 `아이템 능력 차이`라고 표시한다. 최종 캐릭터 능력치나 실제 DPS의 변화로 표현하지 않는다.

### 기본 능력과 무기 강화

| 항목 | 표시 규칙 |
| --- | --- |
| 무기 속성별 피해 | 최소·최대 피해를 각각 뺀다. 예: 12~18과 8~12 → `+4~+6` |
| 초당 공격 횟수 | 두 자리까지 표시한다. 무기 자체의 공격 횟수 차이다 |
| 무기 치명타 확률 | 확률 값의 차이를 `%p`로 표시한다 |
| 방어구 기본 능력 | 같은 의미의 Base 옵션끼리 수치를 비교한다 |
| 무기 고유 강화 | 강화 반영 무기 수치를 비교하고, 기존 강화 상세 영역을 별도로 유지한다 |

무기 수치는 기존 `EquipmentData.WeaponStats`와 같은 값을 사용한다. 고유 강화가 이미 반영된 피해·치명타·공속에 강화 수치를 다시 더하지 않는다. 무기 캐시는 Base와 고유 강화만 포함하며 일반 장비 옵션은 별도 영역에서 비교한다. [src: Assets/Scripts/Data/ItemData.cs, Assets/Scripts/Manager/TooltipManager.cs `BuildEquipmentContent`, Docs/combat/combatSystem.md §장비 옵션 책임 경계]

### 장비 옵션

기본 능력·고유 옵션·접두·접미를 구분한다. 옵션 티어는 문맥 정보로 표시하고, 실제 차이는 롤된 값으로 계산한다. 동일 옵션이 T3와 T5인 경우에도 같은 행에서 비교할 수 있다.

첫 구현의 수치 비교는 **같은 ModTableId와 같은 ModSlot**이며 의미가 확인된 수치형 옵션으로 제한한다. 이 조건이면 적용 방식·대상 스탯·속성·태그도 같은 테이블 정의를 사용한다. 같은 키의 반복 옵션은 가산 가능한 종류만 합산하며, 이름이나 Group만 같다는 이유로 합치지 않는다. 다른 ModTableId를 같은 효과로 대응시키는 규칙은 후속 확장으로 남긴다.

| 상황 | 표시 규칙 |
| --- | --- |
| 양쪽에 같은 가산형 수치 옵션이 있음 | 장착 카드의 값 옆에 `교체 시` 차이를 표시한다 |
| 한쪽에만 가산형 수치 옵션이 있음 | `교체 시 추가` 또는 `교체 시 제거`를 표시하고, 해당 옵션 기여분은 없는 쪽을 0으로 계산한다 |
| 고정 치명타와 치명타 증가율 | 서로 다른 항목으로 표시한다 |
| 공격 전용·주문 전용·조건부 옵션 | 적용 조건을 문구에 함께 표시하며 다른 조건의 옵션과 합치지 않는다 |
| 발동형·Override·의미를 지원하지 않는 옵션 | 원문과 `추가`·`제거`·`변경` 상태만 표시하고 수치 우열을 판단하지 않는다 |
| 테이블 참조가 없거나 계산할 수 없는 값 | 상세 확인 불가를 표시하고 차이는 생략한다 |

정확히 같은 옵션이 없는 경우 이를 다른 행의 수치와 임의로 대응시키지 않는다. 예를 들어 후보의 치명타 증가율과 현재 장비의 고정 치명타는 각각 추가·제거된 능력으로 보인다.

옵션 문구는 기존 `EquipmentOptionText`를 공유한다. 태그와 차이 표시는 그 문구를 보완하되, 제련소와 일반 툴팁에서 같은 옵션을 다르게 설명하지 않는다. `% 증가` 옵션의 10%와 15% 차이는 `증가율 +5%p`로 표시하며 최종 능력치가 5% 오른다는 뜻으로 쓰지 않는다. [src: Assets/Scripts/Item/EquipmentOptionText.cs, Assets/Scripts/Common/Tables.cs `ModTable`, Docs/combat/combatSystem.md §스킬 공격 프로필 구성]

### 색과 판단

일반적으로 높을수록 유리한 것으로 정의한 능력은 증가를 녹색, 감소를 붉은색으로 표시한다. 부호와 숫자를 함께 적어 색만으로 구분하지 않는다. 동일한 값은 차이 표시를 생략한다.

피해 범위의 최소값은 높아지고 최대값은 낮아지는 등 이점이 섞인 경우에는 중립 색을 사용하고 두 차이를 그대로 표시한다. 조건부 효과나 판단 기준이 없는 효과도 중립 색을 사용한다. 아이템 전체에 `더 좋은 장비` 같은 자동 판정이나 종합 점수를 붙이지 않는다.

## 첫 구현 범위와 후속 확장

첫 구현에는 인벤토리 장비 단일 툴팁의 `[Shift] 비교` 안내, Shift 유지 비교, 두 장·세 장 카드 상세, 수치형 옵션 차이, 빈 슬롯 처리, 화면 위치 기준 좌·우클릭 장착, 비교 표시와 장착 대상의 일치, 장착 후 표시 갱신, 화면 경계 및 긴 옵션 처리를 함께 포함한다. 장착 슬롯 자체의 호버와 스킬북·스킬 페이지·소비 아이템은 안내 없이 기존 단일 툴팁을 사용한다.

후속 확장은 다음 순서로 검토한다.

1. **교체 후 캐릭터 능력치 미리보기:** 실제 계산 규칙을 재사용해 최대 체력·방어도·저항 등의 교체 결과를 표시한다. 저항 상한과 조건부 옵션을 반영한다.
2. **선택 스킬의 공격 프로필 미리보기:** 선택한 스킬북·페이지·태그와 현재 상태를 명시하고 교체 전후를 계산한다. 명중 대상·타격 횟수 등을 정의하기 전에는 실제 DPS라고 표시하지 않는다.
3. **양손 및 쌍수 설계 반영:** 기존 장착 규칙의 구현과 함께 왼손 해제 등 전체 변경을 미리 보여준다.
4. **상점 구매 전 비교와 다른 인벤토리 아이템 비교:** 첫 구현의 표시·비교 규칙을 재사용한다.
5. **드래그 앤 드롭:** 비교 중 누른 버튼은 드래그를 시작하지 않는다는 규칙을 유지한다. 드래그로 판정된 입력은 원래 칸에 다시 놓더라도 클릭 장착을 실행하지 않는다. Shift 없는 클릭의 동작은 드래그 방식을 정할 때 결정한다. 누른 채 끌기 방식이면 현행 클릭 장착을 유지하고, 클릭으로 집는 방식이면 클릭은 집기가 되며 클릭 장착은 Shift+클릭으로만 한다.
6. **컨트롤러 조작:** 포커스한 칸을 기준으로 버튼 안내를 표시한다. 비교 버튼을 누르고 있는 동안 LB/RB는 화면 왼쪽·오른쪽 칸에 바로 장착하고, 그 밖에는 A로 집고 놓는다. 안내 아이콘은 마지막으로 사용한 입력 장치에 맞춰 바꾼다. 현행 슬롯은 마우스 이벤트만 받으므로 별도 작업이 필요하다. [src: Assets/Scripts/UI/UICharacter.cs]

캐릭터 스탯과 공격 프로필은 글로벌 옵션·스킬 태그·무기 기본값을 함께 소비한다. 후속 미리보기는 아이템 옵션 합계만으로 최종 수치를 추정하지 않고, 라이브 플레이어를 임시로 장착·해제하는 방식도 사용하지 않는다. [src: Docs/combat/combatSystem.md §스킬 공격 프로필 구성·§공격 속도 / 시전 속도, Assets/Scripts/Common/System/System_SkillAttackProfileCalculation.cs, Assets/Scripts/Common/System/System_StatCalculation.cs]

## 구현 연결과 완료 기준

| 연결 지점 | 역할 |
| --- | --- |
| `UICharacter` | 호버 중인 인벤토리 아이템과 비교 상태를 관리한다. 비교 중 클릭은 누른 버튼을 화면 위치의 슬롯으로 바꿔 장착하고, Shift 없는 클릭은 자동 선택 규칙을 사용한다 |
| `Character.uxml`과 `Character.uss` | 장비 12칸·인벤토리 칸 배치와 비교 대상 칸 강조 스타일을 정의한다. 칸의 호버 진입·이탈, 누른 버튼, 같은 칸에서 뗀 클릭은 `UICharacter`가 칸 element 콜백으로 받고, 칸 표시는 기억한 아이템 참조·수량이 데이터와 다를 때만 다시 그린다 |
| `EquipHelper` | 장착 가능 슬롯 판정, 자동 선택, 칸이 두 개인 장비의 화면 왼쪽·오른쪽 슬롯 조회를 공유한다 |
| `TooltipManager` | 하단 Shift 안내가 있는 단일 상세와 두 장·세 장 비교 상세를 표시하고 배치·스크롤·닫기 수명을 관리한다 |
| `Tooltip.uxml`과 `Tooltip.uss` | 카드, 정렬된 행, `교체 시` 차이 스타일, 빈 슬롯, Shift 키캡, 조작 안내를 정의한다 |
| `EquipmentOptionText`와 비교 계산 책임 | 문구를 공유하고 의미가 같은 지원 항목의 값만 비교한다 |
| UI 입력 액션 | Shift 유지 비교를 추가한다 |

공용 `Show(item, rect)`는 단일 아이템 표시로 유지하고 인벤토리 장비에만 비교 문맥을 전달한다. 비교 계산은 두 아이템 데이터를 받는 순수 로직으로 두고 장착 카드마다 호출한다. 호버·비교 상태는 UI 인스턴스가 소유한다. 별도 전역 캐시나 ECS 시스템은 추가하지 않는다.

비교를 열기만 해서는 인벤토리·장비·저장 상태를 변경하지 않는다. 무기 상세는 기존 캐시 조회 규칙을 사용한다. Shift를 누르거나 뗄 때, 아이템을 전환할 때, 장착 상태가 바뀔 때만 콘텐츠를 다시 만들고 매 프레임 옵션을 집계하지 않는다. 입력·이벤트 콜백은 초기화 시 등록해 재사용하며, 화면 크기가 확정될 때 위치를 보정한다.

장착 직전에는 인벤토리 슬롯과 ItemInstanceId, 누른 버튼에 대응하는 슬롯의 장착 가능 여부, 현재 장착 아이템을 다시 확인한다. 그 사이 대상이 바뀌었다면 오래된 비교 화면으로 교체하지 않고 비교를 갱신한 뒤 다시 클릭하도록 한다.

| 확인 상황 | 완료 기준 |
| --- | --- |
| 갑옷 호버 | 단일 툴팁 맨 아래에 `[Shift] 비교` 안내가 보인다 |
| 갑옷 호버 중 Shift 누름·뗌 | 누르면 현재 갑옷과 정렬된 비교가 열리고 슬롯이 강조되며, 떼면 단일 툴팁으로 돌아온다 |
| Shift를 누른 채 다른 장비로 이동 | 대기 없이 새 장비의 비교로 바뀐다 |
| 반지 양쪽 장착 후 Shift+좌클릭·Shift+우클릭 | 좌클릭은 화면 왼쪽의 오른쪽 반지, 우클릭은 화면 오른쪽의 왼쪽 반지만 교체되고 이전 장비가 인벤토리로 돌아온다 |
| 오른쪽 반지만 장착 | 우클릭 카드가 `장착된 아이템 없음`이며 Shift+우클릭으로 빈 왼쪽 칸에 장착된다 |
| 칸이 하나인 장비에 Shift+우클릭 | 해당 칸에 장착된다 |
| Shift 없이 클릭 | 현행 자동 선택 규칙대로 장착된다 |
| 장착 후 Shift 유지 | 칸으로 돌아온 이전 장비와 새로 장착한 아이템의 비교로 바로 바뀐다 |
| 왼손 방패와 인벤토리 무기 비교 | 우클릭 카드가 방패이며 서로 다른 능력을 모두 보여주고 우클릭 안내가 왼손 방패 교체임을 알린다 |
| 고정 치명타·증가 치명타·공격 전용 옵션 | 효과와 적용 조건이 다른 행에 분리된다 |
| 무기 고유 강화가 있는 장비 | 기존 단일 툴팁의 무기 수치와 일치하며 강화가 중복 반영되지 않는다 |
| 후보에만 있는 옵션·현재 장비에만 있는 옵션 | `교체 시 추가`·`교체 시 제거`가 모두 보이고 현재 장비의 장점이 사라지지 않는다 |
| 최소 피해 증가·최대 피해 감소 | 두 차이를 중립 색으로 표시한다 |
| 좁은 화면·화면 모서리·최대 길이 옵션 | 세 장 카드와 조작 안내를 볼 수 있고 모든 옵션을 스크롤할 수 있다 |
| 다른 UI 전면·입력 필드 포커스 | Shift를 눌러도 비교가 열리지 않는다 |
| 아이템 제거·장비 변경·UI 닫기 | 오래된 비교와 강조가 남지 않는다 |
| 비교만 열고 닫기 | 장비·인벤토리와 플레이어 저장 상태가 바뀌지 않는다 |
| 스킬북·소비 아이템·장착 슬롯 호버 | Shift 안내 없이 기존 상세 흐름이 유지된다 |

구현 순서는 버튼별 장착 슬롯 연결 → 단일 툴팁 안내와 Shift 전환 → 카드 상세 → 옵션 차이 → 배치·스크롤·수명 처리다. 완료 판정에는 위 상황의 현재 Unity 프로젝트 PlayMode 확인과 변경 범위의 기존 컴파일 검증을 포함한다.
