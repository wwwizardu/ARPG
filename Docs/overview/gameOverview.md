# 게임 전체 개요 (Game Overview)

## 프로젝트 정보
- **장르**: 오픈월드 액션 RPG + 마을 건설 시뮬레이션
- **참고 게임**:
  - **코어 키퍼**: 탑다운 시점, 실시간 전투, 절차적 생성 던전, 채집/크래프팅
  - **림월드**: NPC 관계 시스템, 자율적 NPC 행동, 다이나믹 스토리텔링
- **핵심 차별점**: 플레이어가 직접 전투하는 액션 RPG + NPC들의 자율적 관계/행동 시스템

---

## 게임 구조

### 1. 코어 루프
```
[탐험] → [전투/채집] → [자원 획득]
   ↓                           ↓
[마을 귀환] ← [NPC 상호작용] ← [마을 발전]
```

**플레이어 경험**:
1. 오픈월드를 탐험하며 던전 발견
2. 실시간 전투로 몬스터 처치 및 보스 격파
3. 자원/아이템 수집
4. 마을로 돌아와 NPC와 상호작용
5. NPC들이 자율적으로 마을 발전 (건설, 자원 생산)
6. NPC를 동료로 영입하여 다시 탐험
7. NPC와 대화·선물로 관계를 쌓고, 깊어지면 소망·보답 등 특별 사건 발생

---

## 게임 3대 축

### Axis 1: 플레이어 액션 (코어 키퍼 스타일)
- **실시간 탑다운 전투**
- **오픈월드 탐험** (절차적 생성 맵)
- **절차적 생성 던전** (보스, 보물, 함정)
- **채집 & 크래프팅**
- **장비 & 스킬 성장**

### Axis 2: NPC 자율 시뮬레이션 (림월드 스타일)
- **8가지 성격 스탯**에 따른 개별 행동
- **NPC 간 관계 형성** (친구, 연인, 라이벌)
- **자율적 일일 루틴** (식사, 작업, 수면, 사교)
- **직업별 자원 생산** (농부, 대장장이, 광부 등)
- **시간 경과에 따른 마을 발전**

### Axis 3: 플레이어-NPC 상호작용
- **30가지 상호작용 행동** (대화, 거래, 설득, 위협, 선물 등)
- **관계 기반 판정** (NPC 성격 + 관계 4축)
- **동적 시나리오 생성** (관계에 따라 대화·소망·이벤트 달라짐)
- **동료 시스템** (NPC를 파티원으로 영입)
- **관계·선물 루프** (대화로 사연 알아가기 → 선호 유추 → 선물 → 호감도 → 소망 충족 → 보답)

## 게임 흐름 (거시 진행)

### 진행 엔진 — 탐험 · 보스 · 성장 · 확장

게임의 거시 진행은 하나의 반복 루프로 돈다:

```
[탐험] → [거점·유적의 보스 격파] → [장비·스킬·빌드 강화] → [더 바깥 영역 진출] → 반복
```

바깥으로 나아갈수록 강한 적과 보스를 만나고, 격파해 강해지며, 그 힘으로 더 멀리 나아간다. **"안전 반경을 바깥으로 밀어내는 공간적 확장"** 이 진행의 골격이다.

### 난이도 모델 — 거리 기울기 + 국지 변동

- 시작 마을(원점)에서 **멀수록 대체로 난이도↑** — `Zone = max(|청크X|, |청크Y|) + 1` (1~99)이 거리 지표.
- 단 **완전 비례는 아니다.** 같은 거리라도 바이옴·지역·배치된 콘텐츠(보스 거점, 유적 등급 등)에 따라 난이도가 달라진다.
- 즉 진행은 "동심원 레벨업"이 아니라 **거리 기울기 위에 국지적 난이도 편차가 얹힌 지형**이다. 플레이어는 무작정 먼 곳이 아니라 "갈 만한 다음 거점"을 골라 전진한다.

### 핵심 재미 (검증 1순위) — 창발 내러티브

이 탐험 위에 게임의 정체성이 얹힌다: **절차적으로 생성된 세계 역사와 NPC 관계를 배경으로, LLM이 단계별 대화·선호·소망·세부 디테일을 생성하고, 플레이어가 그 사연을 알아가며 선물로 관계를 맺는다.**

```
절차적 역사(연대기·왕국·정복·폐허) ┐
NPC 관계(가족·원한·파벌·Sentiment) ├─▶ LLM 컨텍스트 ─▶ 대화/선호/소망/디테일 ─▶ 플레이어가 유추·선물·소망 충족 ─▶ 호감도·보답·역사에 반영
유적 단편(종족·운명·바이옴)        ┘
```

탐험으로 만나는 장소와 NPC가 *고유한 사연*을 갖고, 대화가 깊어질수록 그 사연이 드러난다. 플레이어는 사연에서 *무엇을 주면 좋아할지*를 헤아려 선물하고, 호감도가 쌓이면 NPC가 깊은 소망을 털어놓고 또 보답한다. **이 관계 루프가 재미있는지(몰입되는지)를 가장 먼저 검증한다.** (이 루프는 *몰입 레이어*이지 더 깊은 지역으로의 진출 동기가 아니다 — 진출 동기는 [메인 이벤트(월드 이벤트) 등 별도 시스템](../world_history/WORLD_EVENT_DESIGN.md) 몫.)

> 백본(절차적 역사 + NPC 관계, R0~R4)은 이미 대부분 구현됨 ([WORLD_HISTORY_PLAN.md](../world_history/WORLD_HISTORY_PLAN.md)). 그 위에 얹는 LLM 생성층의 상세 설계는 [NARRATIVE_ENGINE_DESIGN.md](../world_history/NARRATIVE_ENGINE_DESIGN.md).

### 후속 레이어 (현재 범위 밖, 추후)

핵심 재미 검증 후 얹을 확장 — 지금은 의도적으로 미룬다:

- **마을 자가성장** — 정착민이 게임 시간·자원으로 마을을 Seed→City로 키움 ([VILLAGE_GROWTH_STAGES.md](../village/VILLAGE_GROWTH_STAGES.md))
- **몬스터 침공 / 방어** — 위협도 상승, 외곽 벽·경비 ([VILLAGE_GROWTH_STAGES.md](../village/VILLAGE_GROWTH_STAGES.md) Town/City 목표)

> **엔드게임**: 샌드박스 무한 운영(잠정) — 명확한 승리 조건 없이 더 깊은 영역 도전 + 세계 운영. 핵심 재미 검증 결과에 따라 구체화.

## 주요 시스템 개요 (상세는 별도 문서 참조)

### 1. 전투 시스템 (combatSystem.md)
- 실시간 액션 전투
- 스킬/장비 기반 성장
- 동료 AI 전투 참여

### 2. 동료 시스템 (companionSystem.md)
- NPC를 파티원으로 영입
- 관계도에 따른 능력치 보너스
- 동료 전용 대화 및 이벤트

### 3. 던전 시스템 (dungeonSystem.md)
- 절차적 생성 (방, 복도, 보스룸)
- 난이도별 던전 (Tier 1~5)
- 보스 패턴 및 보상

### 4. NPC 상호작용 + 관계·선물 시스템 (interactionSystem.md)
- 30가지 행동 (대화, 거래, 설득, 위협 등)
- 판정 공식 (NPC 성격 + 관계 4축)
- 상호작용 결과에 따른 관계 변동
- **관계·선물 몰입 루프** (§4): 대화로 사연 알아가기 → 선호 유추 → 선물 → 호감도 → 보답

### 5. 마을 시스템 (townDesign.md)
- NPC 자율 행동 및 일일 루틴
- 자원 생산-가공-소비 체인
- 건물 건설 및 마을 발전 단계

### 6. 퀘스트 시스템 — NPC 소망 (QUEST_SYSTEM_DESIGN.md)
- 관계가 깊어질 때 떠오르는 NPC의 **특정 소망(Wish)** 추적·충족
- 충족 → 대폭 호감도 + 보답 (관계 루프로 되먹임)
- *(게시판·수락 없음 — 대화로 떠오르는 "소망"이 옛 퀘스트 계약 모델 대체. 진출 동기는 메인 이벤트 등 별도)*

### 7. 월드 이벤트 — 도전 콘텐츠 (WORLD_EVENT_DESIGN.md)
- 절차적 역사·관계가 낳은 **위협**(고대신 각성·역병 확산·침공 등)을 플레이어가 맞섬
- 방치 시 악화 + 거리 기울기로 난이도 스케일 → **진출 동기(메인 이벤트)** 레이어
- 해결 → 연대기·명성으로 되먹임 (몰입 루프와 다른 *도전 축*)

## 기술 스택

### Unity 아키텍처
- **Engine**: Unity 6000.0.42f1 (LTS)
- **Rendering**: URP (Universal Render Pipeline) 17.0.4
- **Input**: Unity Input System 1.13.1

### 커스텀 ECS (Entity Component System)
- **NOT Unity DOTS**: 자체 구현 ECS
- **Component**: 순수 데이터 구조체 (struct)
- **System**: 로직 처리 클래스 (ISystem 인터페이스)
- **Storage**: SparseSet (O(1) 접근, 캐시 친화적)

### 절차적 생성
- **맵**: Perlin Noise 기반, 청크 로딩 시스템
- **던전**: Room + Corridor 알고리즘
- **몬스터 스폰**: 확률 기반 배치
