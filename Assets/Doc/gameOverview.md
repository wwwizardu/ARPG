# 게임 전체 개요 (Game Overview)

## 프로젝트 정보
- **장르**: 오픈월드 액션 RPG + 마을 건설 시뮬레이션
- **참고 게임**:
  - **코어 키퍼**: 탑다운 시점, 실시간 전투, 절차적 생성 던전, 채집/크래프팅
  - **림월드**: NPC 관계 시스템, 자율적 NPC 행동, 다이나믹 스토리텔링
- **핵심 차별점**: 플레이어가 직접 전투하는 액션 RPG + NPC들의 자율적 관계/행동 시스템

---

## 게임 구조

### 1. 코어 루프
```
[탐험] → [전투/채집] → [자원 획득]
   ↓                           ↓
[마을 귀환] ← [NPC 상호작용] ← [마을 발전]
```

**플레이어 경험**:
1. 오픈월드를 탐험하며 던전 발견
2. 실시간 전투로 몬스터 처치 및 보스 격파
3. 자원/아이템 수집
4. 마을로 돌아와 NPC와 상호작용
5. NPC들이 자율적으로 마을 발전 (건설, 자원 생산)
6. NPC를 동료로 영입하여 다시 탐험
7. NPC 관계에 따라 특별 퀘스트/이벤트 발생

---

## 게임 3대 축

### Axis 1: 플레이어 액션 (코어 키퍼 스타일)
- **실시간 탑다운 전투**
- **오픈월드 탐험** (절차적 생성 맵)
- **절차적 생성 던전** (보스, 보물, 함정)
- **채집 & 크래프팅**
- **장비 & 스킬 성장**

### Axis 2: NPC 자율 시뮬레이션 (림월드 스타일)
- **8가지 성격 스탯**에 따른 개별 행동
- **NPC 간 관계 형성** (친구, 연인, 라이벌)
- **자율적 일일 루틴** (식사, 작업, 수면, 사교)
- **직업별 자원 생산** (농부, 대장장이, 광부 등)
- **시간 경과에 따른 마을 발전**

### Axis 3: 플레이어-NPC 상호작용
- **30가지 상호작용 행동** (대화, 거래, 설득, 위협, 선물 등)
- **관계 기반 판정** (성격 + 관계 스탯 + 플레이어 스탯)
- **동적 시나리오 생성** (관계에 따라 이벤트 달라짐)
- **동료 시스템** (NPC를 파티원으로 영입)
- **퀘스트 발생** (NPC 목표 달성 도움)

## 게임 흐름 (게임 시작 ~ 엔드게임)

### Phase 1: 정착 (Settlement) - 초반 1~2시간
**목표**: 생존 및 기본 마을 구축

- 플레이어는 작은 정착지에서 시작 (NPC 3~5명)
- **튜토리얼**: 기본 전투, 채집, NPC 대화, 자원 기부
- 근처 필드에서 약한 몬스터 처치, 기본 자원 수집
- 첫 번째 던전 발견 및 클리어
- 마을에 첫 건물 건설 (창고, 대장간)

### Phase 2: 확장 (Expansion) - 중반 5~10시간
**목표**: 마을 발전 및 NPC 영입

- 마을 단계 상승: 정착지 → 작은 마을 → 마을
- NPC 증가 (8~20명), 직업 다양화
- 더 깊은 던전 탐험, 희귀 자원 획득
- **NPC 관계 형성**: 호감도 상승, 친구/연인 관계
- **동료 시스템 해금**: 첫 NPC 동료 영입
- **퀘스트 발생**: NPC의 개인 목표 달성 도움
- 외부 위협 증가 (몬스터 습격, 도적단)

### Phase 3: 번영 (Prosperity) - 후반 10~20시간
**목표**: 도시 발전 및 엔드게임 콘텐츠

- 마을 단계 상승: 소도시 → 도시
- 전문 시설 건설 (도서관, 훈련장, 성벽)
- **고난이도 던전**: 강력한 보스, 희귀 아이템
- **복잡한 NPC 관계망**: 삼각관계, 파벌 형성
- **대규모 이벤트**: 전쟁, 역병, 대규모 몬스터 습격
- **엔드게임 목표**: 최종 보스 격파, 완벽한 도시 완성

## 주요 시스템 개요 (상세는 별도 문서 참조)

### 1. 전투 시스템 (combatSystem.md)
- 실시간 액션 전투
- 스킬/장비 기반 성장
- 동료 AI 전투 참여

### 2. 동료 시스템 (companionSystem.md)
- NPC를 파티원으로 영입
- 관계도에 따른 능력치 보너스
- 동료 전용 대화 및 이벤트

### 3. 던전 시스템 (dungeonSystem.md)
- 절차적 생성 (방, 복도, 보스룸)
- 난이도별 던전 (Tier 1~5)
- 보스 패턴 및 보상

### 4. NPC 상호작용 시스템 (interactionSystem.md)
- 30가지 행동 (대화, 거래, 설득, 위협 등)
- 판정 공식 (성격 + 관계 + 플레이어 스탯)
- 상호작용 결과에 따른 관계 변동

### 5. 마을 시스템 (townDesign.md)
- NPC 자율 행동 및 일일 루틴
- 자원 생산-가공-소비 체인
- 건물 건설 및 마을 발전 단계

### 6. 퀘스트 시스템 (questSystem.md)
- NPC 개인 목표 기반 퀘스트
- 관계 기반 특별 퀘스트
- 메인 스토리 퀘스트

## 기술 스택

### Unity 아키텍처
- **Engine**: Unity 6000.0.42f1 (LTS)
- **Rendering**: URP (Universal Render Pipeline) 17.0.4
- **Input**: Unity Input System 1.13.1

### 커스텀 ECS (Entity Component System)
- **NOT Unity DOTS**: 자체 구현 ECS
- **Component**: 순수 데이터 구조체 (struct)
- **System**: 로직 처리 클래스 (ISystem 인터페이스)
- **Storage**: SparseSet (O(1) 접근, 캐시 친화적)

### 절차적 생성
- **맵**: Perlin Noise 기반, 청크 로딩 시스템
- **던전**: Room + Corridor 알고리즘
- **몬스터 스폰**: 확률 기반 배치
